# Workflow tạo file Dashboard Master mới

Khi người dùng yêu cầu tạo mới Dashboard:

1. Sử dụng file mẫu `assets/EBM_Dashboard_Master_Template.xlsx` làm nền nếu phù hợp.
2. Không đưa dữ liệu mẫu giả vào các sheet nghiệp vụ.
3. Bảo đảm có đủ sheet theo cấu trúc chuẩn.
4. Bảo đảm có dropdown chuẩn cho trạng thái, ưu tiên, task và loại nguồn.
5. Bảo đảm `Dashboard_Summary` chỉ tổng hợp từ bản ghi thực tế.
6. Khi xuất file mới, nêu rõ:
   - file đã tạo;
   - sheet đã có;
   - dữ liệu nào chưa được nhập;
   - cách dùng trong các lần cập nhật tiếp theo.
