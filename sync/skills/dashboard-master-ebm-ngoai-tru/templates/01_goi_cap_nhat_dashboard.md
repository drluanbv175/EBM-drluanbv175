# Mẫu GÓI CẬP NHẬT DASHBOARD

Sử dụng mẫu này khi không thể chỉnh trực tiếp file Excel Master.

## A. Tóm tắt kỳ cập nhật

| Trường | Nội dung |
|---|---|
| Task nguồn | |
| Kỳ báo cáo | |
| Phạm vi rà soát | |
| Số cập nhật đủ điều kiện đưa vào Dashboard | |
| Kết luận nhanh | |

## B. Change Log mới

| Change ID | Ngày ghi nhận | Task nguồn | Chuyên khoa/chủ đề | Vấn đề lâm sàng | Cập nhật đã xác minh | Hành động đề nghị | Đối tượng áp dụng | Thận trọng | Độ chắc chắn | Độ mạnh khuyến cáo | Nguồn/năm/phiên bản | Evidence ID | Trạng thái | Ghi chú |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

## C. Evidence Register mới

| Evidence ID | Change ID liên kết | Ngày xác minh | Loại nguồn | Tổ chức/tác giả | Tên tài liệu | Năm/phiên bản | Quần thể | Kết luận liên quan | Grading nguyên bản | URL/nguồn truy nguyên | Đã kiểm chứng? | Ghi chú |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

## D. Action Register mới

| Action ID | Change ID liên kết | Hành động | Mức ưu tiên | Người/đơn vị cần xác nhận | Sản phẩm cần cập nhật | Trạng thái | Hạn đề nghị | Ghi chú |
|---|---|---|---|---|---|---|---|---|

## E. Nội dung chưa nên thay đổi thực hành

| Chủ đề | Tín hiệu mới | Vì sao chưa đủ áp dụng | Cần theo dõi tiếp |
|---|---|---|---|

## F. Kết luận
Chọn một:
- Có cập nhật đã xác minh cần xem xét thay đổi thực hành.
- Có cập nhật cần theo dõi nhưng chưa đủ căn cứ thay đổi thực hành.
- Không ghi nhận cập nhật đã xác minh có khả năng thay đổi thực hành trong kỳ này.
